Project Goal

BitShyft is an ASIC based transmission controller I'm developing to swap a 4l60e transmission into my computer-less 82' Chevy pickup. The project pillars are to make it rock solid reliable, self-monitoring to aid with diagnostics, avoid incorrect downshits at all costs, and provide a kit that is easier to install than any other controller on the market. See more here: BitShyft overview documentation

Project Goal

11/9/25 update: This project has spawned a spinoff, the transmission has an electric speedometer output, while my truck uses a mechanical cable. I'm modularizing the Variable Reluctance frontend and adding a motor to drive the cable. Once the prototype is complete, I'll open the source so that it can be modified to fit other applications
